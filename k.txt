5. Right-click Project -> Maven -> Update Project
   Downloads and refreshes Maven dependencies.

6. Right-click Project -> Run As -> Maven build...
   Opens the Maven build window.

7. Goals: clean install -> Run
   Deletes old files, compiles, tests, packages, and installs the project.

8. Check the target folder
   Contains the generated JAR or WAR file.

DOCKER STEPS

1. Create a file named Dockerfile
   Defines how Docker should build and run the application.

2. Build the Maven project first using clean install or clean package
   Creates the JAR/WAR artifact required by Docker.
JAR
FROM eclipse-temurin:17-jre(17 is java vserion see in pom xml)

WORKDIR /app

COPY target/*.jar app.jar

EXPOSE 8080

CMD ["java", "-jar", "app.jar"]
WAR
FROM maven:3.9-eclipse-temurin-8 AS build

WORKDIR /app

COPY . .

RUN mvn clean package

FROM tomcat:9-jdk8

COPY --from=build /app/target/*.war /usr/local/tomcat/webapps/ROOT.war

EXPOSE 8080

CMD ["catalina.sh", "run"]
3. docker build -t ors .
   Builds a Docker image named ors from the Dockerfile.

4. docker images
   Shows Docker images and verifies that the ors image was created.

5. docker run -d -p 8080:8080 --name ors-container ors
   Creates and starts a container from ors and maps host port 8080 to container port 8080.

6. docker ps
   Shows currently running containers.

7. docker logs ors-container
   Shows the output and logs of the ORS application.

8. Open http://localhost:8080
   Accesses the application running inside the Docker container.

9. docker stop ors-container
   Stops the running container.

10. docker start ors-container
    Starts the existing stopped container.

12. docker rm ors-container
    Deletes the container after it has been stopped.

DOCKER HUB STEPS

1. docker login
   Authenticates Docker with your Docker Hub account.

2. docker tag ors yourusername/ors:latest
   Creates a Docker Hub-compatible tag for the local ors image.

3. docker push yourusername/ors:latest
   Uploads the image to your Docker Hub repository.

4. docker pull yourusername/ors:latest
   Downloads the image from Docker Hub to verify that it was successfully pushed.
